# 🏋️ Smart Gym Planner

Smart Gym Planner is a Flask-based web application that generates personalized workout and diet plans based on the user's BMI, fitness goals, and preferences.

---

## 🚀 Features

- User authentication system
- BMI calculation
- Personalized workout plan generation
- Diet recommendation system
- Secure login and password hashing
- Email notifications and password reset
- Modern dark-themed gym UI

---

## 🧠 Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript
- bcrypt

## ⚙️ Installation

Clone the repository:
https://github.com/premnandkishore/smart-gym-planner.git


Navigate to the project folder:

**cd smart-gym-planner** : Install dependencies:

pip install -r requirements.txt

Run the application: python app.py

Open in browser : http://127.0.0.1:5000

## 🎯 Project Goal

The goal of this project is to help users create structured gym plans and maintain a healthy lifestyle using simple AI-based recommendations.
